# 🐐 Hermes Trading Agent

> **你的AI股票研究团队 — 24小时不知疲倦的多空辩论**

## 一句话介绍

Hermes是一个智能股票研究助手，它像一支小型投资银行团队一样工作：5位分析师并行研究 → 多空双方激烈辩论 → 研究总监一锤定音，最终给你一个清晰的S/A/B/C评级和投资建议。

---

## 为什么需要它？

散户vs机构的信息差有多大？

- 机构有分析师团队覆盖每只股票，你只有财经新闻
- 机构有量化模型算估值，你只能看市盈率
- 机构有多空辩论机制校验观点，你只能靠"感觉"

**Hermes把机构投研流程民主化，让个人投资者也能拥有完整的AI研究团队。**

---

## 核心功能

### 1. 📊 五大AI分析师（并行工作）

| 分析师 | 负责领域 | 口头禅 |
|--------|----------|--------|
| Warren分析师 | 基本面财务分析 | "让我看看ROE和现金流..." |
| Chartist陈 | 技术图形分析 | "均线多头排列，趋势向上" |
| CrowdSense萨拉 | 市场情绪解读 | "散户太乐观了，该谨慎" |
| NewsBot新闻官 | 突发事件评估 | "这条新闻会影响下季度财报" |
| MacroMike宏观师 | 行业赛道研究 | "这个行业正在发生结构性变化" |

### 2. 🗣️ 多空辩论机制

不是简单的"买入评级"，而是：
- **看多者**必须找到3个以上支撑数据
- **看空者**必须反驳对方观点
- **研究总监**综合双方论点，做出最终裁决

> 就像一个投资决策会议，不会一个人说了算

### 3. 🎯 S/A/B/C 评级系统

| 评级 | 含义 | 适合人群 |
|------|------|----------|
| **S** | 绝佳机会，必须关注 | 激进型投资者 |
| **A** | 值得关注，逻辑清晰 | 稳健型投资者 |
| **B** | 可以观察，需要更多验证 | 保守型投资者 |
| **C** | 风险较大，谨慎参与 | 不建议买入 |

评分权重：**基本面40% + 技术面30% + 宏观30%**

### 4. ⚡ 智能风控

- **Token预算监控**：每次研究不超过50万token，防止"AI乱花钱"
- **超时降级**：网络慢时不崩溃，逐步返回已完成的分析
- **渐进式报告**：哪怕中途出错，也能拿到部分结论

## 快速开始

### 环境要求
- Python 3.11+
- API密钥（MiniMax/GPT/Claude）

### 安装
```bash
pip install -r requirements.txt
```

### 配置
```bash
cp .env.example .env
# 编辑.env填入你的API密钥
```

### 运行
```bash
# 分析单只股票
python -m agent.research_v1.cli "分析一下 AAPL"

# 查看评级
python -m agent.research_v1.cli "AAPL 现在什么评级"

# 系统状态
python -m agent.research_v1.cli "系统状态"
```

## 技术架构

- **Orchestration**: Hermes Agent (NousResearch)
- **分析师模型**: MiniMax 2.7（低成本高效率）
- **辩论/评审**: GPT-5.4（强大推理能力）
- **决策裁决**: Claude Opus（顶级判断力）
- **存储**: SQLite（轻量、可靠、无额外成本）
- **内存**: 分层记忆系统（无需向量数据库，降低延迟）

---

## 团队分工

| 角色 | 模型 | 任务 |
|------|------|------|
| 分析师团队 | MiniMax 2.7 | 并行研究 |
| 多头/空头 | GPT-5.4 | 辩论 |
| 研究总监 | Claude Opus | 最终决策 |
| 评审/评分 | MiniMax 2.7 | 质量把控 |

> ⚠️ **重要**: 不同任务使用最合适的模型，不是越贵越好

---

## 安全机制

- **6层死亡循环防护**：防止AI无限循环
- **Token预算**：每次任务不超过50万token
- **超时降级**：网络异常时优雅处理
- **人工复核**：AI建议仅供参考
